# avoid.quest

A place to listen and explore the web.

**[Open radio](https://radio.avoid.quest)** to listen to internet stations,
play music links or local files, and shape the sound with effects. Listen to one
station, mix two decks in DJ mode, or connect sources and effects in Node mode.
Your stations and settings stay in your browser; you can export a backup or
install radio as an app.

Visit **[avoid.quest](https://avoid.quest)** for the links hub,
**[feed](https://feed.avoid.quest)** to browse updates, and
**[cwavasape](https://cwavasape.com)** for an internet gallery.
The radio, links hub and Discord bot live in this repository.

Found a bug or have an idea? Use radio's Feedback button or
[open an issue](https://github.com/avoid-quest/avoid.quest/issues/new/choose).
Feedback becomes a public GitHub issue, so leave out personal information.
For private security reports, see [SECURITY.md](SECURITY.md).

Contributions are welcome: start with [CONTRIBUTING.md](CONTRIBUTING.md).
Setup and architecture are in the [development guide](DEVELOPMENT.md).
