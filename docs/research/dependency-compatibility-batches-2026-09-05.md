# Compatible dependency update batches

Research for [Research compatible dependency update batches](https://github.com/avoid-quest/avoid.quest/issues/321), part of [Plan maintainable radio modes, Effects, and monorepo upkeep](https://github.com/avoid-quest/avoid.quest/issues/312).

Checked on **2026-09-05**, against repository commit [`4743b65`](https://github.com/avoid-quest/avoid.quest/commit/4743b6515b83bdf6fd21396696990f54e1d5bc4e), the committed lockfile, current npm metadata, and upstream releases/source. `bun outdated --recursive --no-cache` was rerun with Bun 1.4.2. There are **23 distinct outdated direct dependencies**, counting catalog consumers once and including TypeScript. The table below covers all 23. Bun itself is addressed separately because its pins are not an npm dependency in this repository.

These are **proposed maintenance scopes, not verified upgrades or additional approved implementation tickets**. No dependency was installed or changed. Published peer ranges and source changes support trying these targets; they do not establish that the resulting lockfile, browser playback, Worker startup, or deployment works. Refresh the inventory when implementing, and review any newer target independently.

The useful priorities are the Cloudflare tool pair, the released TanStack DB startup fix, and the formatting/tooling patches. Keep HLS, Sentry, and Astro independently reversible. Do not combine this work with mode architecture, new Effects, product prompt changes, or the separate [Autotune WASM investigation](https://github.com/avoid-quest/avoid.quest/issues/302).
