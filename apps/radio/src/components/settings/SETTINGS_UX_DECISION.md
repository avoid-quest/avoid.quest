# Settings UX decision

The settings information architecture is the compact sidebar layout with the
sections Radios, Playback, MIDI, and Data (Export, Import, Reset). Playback is
one view: the audio settings followed by the "Restore playback state" switch.
The player mode is chosen only from the header toggle, so it is not repeated
in settings. The layout keeps every settings feature, uses the repository's
shadcn/ui styling unchanged, keeps copy minimal, preserves existing default-tab
entry points, and keeps the app version visible in the sidebar and mobile
footer.
