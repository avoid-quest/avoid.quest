# ui

Shared UI component library. shadcn/ui + Radix UI primitives.

## Features

- Components: button, card, input, textarea, select, dialog, dropdown, tabs, carousel, accordion, avatar, badge, skeleton, tooltip, slider, switch, etc
- Theme support: dark/light mode via next-themes, CSS variables, OKLCH color space
- Custom components: avoid-logo, site-logo, mode-toggle, rotary-knob, play-pause-button, user-avatar
- Utilities: cn() for class merging, tailwind-merge integration
- Assets: favicons, icons exported from package

## Connections

- Used by `apps/instarip`: cards, buttons, carousel for posts
- Used by `apps/radio`: form inputs, dialogs, sliders for settings
- Used by `apps/web`: logo, buttons for landing page
